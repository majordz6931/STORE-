# MAJOR STORE — Hacking Tools & Cybersecurity Programs

متجر أدوات اختراق وبرامج إلكترونية بهوية cyber داكنة ولوجو دائري متغيّر الألوان، يحمل شعار "MAJOR STORE" في أعلى الموقع بشكل دائم.

## معلومات الدخول (حماية حقيقية 🔒)

- **المتجر**: افتح `index.html`
- **لوحة التحكم**: افتح `admin.html`
- اللوحة **محمية بالكامل** — عند فتحها تظهر شاشة الدخول دائماً ولا يمكن تجاوزها:
  - الدخول يتم فقط عبر **Supabase Auth** ببيانات المستخدم الحقيقي الذي أنشأته في `Authentication → Users` (مثال: `admin@majorstore.store` / `yemavava91@@@@@#####`)
  - يكتب المستخدم الاسم فقط: `admin` (يُحوَّل تلقائياً إلى `admin@majorstore.store`) أو البريد الكامل
  - **لا يوجد أي تجاوز محلي أو كلمة سر مخزنة في الكود** — بدون حساب Supabase صحيح تبقى شاشة الدخول
  - الجلسة تُحفظ للتبويب فقط (`sessionStorage`)؛ جديد التبويب أو زر `logout` يعيد شاشة الدخول

## مزايا الموقع

- 🌍 **ثلاث لغات كاملة**: العربية 🇸🇦 + الفرنسية 🇫🇷 + الإنجليزية 🇬🇧 — كل النصوص والأقسام والمنتجات قابلة للتحرير باللغات الثلاث
- 🖼️ بانر MAJOR STORE ثابت في أعلى الموقع (دائم الظهور)
- 🏪 **قاعدة بيانات مشتركة (Supabase)**: أي منتج ينشره المدير يظهر فوراً للزوار من أي جهاز
- ✉️ زر تواصل عائم — يرسل الزائر رسالة تصل إلى لوحة التحكم (Messages)
- 🎛️ **التحكم بكل أقسام الموقع**: إظهار/إخفاء أي قسم (Hero، الأقسام، المتجر، المزايا، من نحن، الدفع، النشرة) + تعديل نصوصه باللغات الثلاث من لوحة التحكم
- 💰 **مدفوعات رقمية حقيقية**: عند اختيار طريقة crypto يختار الزائر **الشبكة** (مثال: BSC — BNB Smart Chain (BEP20)) ويعرض العنوان + **رمز QR** للدفع، مثبت من لوحة التحكم
- 💵 أسعار بالدولار الأمريكي فقط ($)
- 💳 طرق دفع: Bitcoin, Ethereum, USDT (TRC20/ERC20/BEP20), BNB (BEP20), Litecoin, Monero, PayPal, Visa/Mastercard, Western Union, Wise, BaridiMob/CCP, الدفع عند الاستلام
- 🎟️ لوحة كوبونات كاملة (إنشاء/حذف/تعطيل)
- 🛒 سلة شراء محلية + طلبات تُرسل إلى Supabase
- ⚙️ لوحة تحكم بتصميم جديد كلياً: **شريط تنقّل علوي** (فوق وليس في القائمة السفلية) + شريط جانبي، مع logout في الأعلى
  - منتجات (AR/FR/EN) / أقسام / كوبونات / مدفوعات وCrypto / Hero / Sections / طلبات / رسائل / إعدادات
- 🔐 على المتجر (موبايل): رابط "لوحة التحكم" يظهر في **أعلى** قائمة القائمة، بارزاً بوضوح

## إعداد Supabase (مرة واحدة)

1. أنشئ مشروعاً في [supabase.com](https://supabase.com).
2. افتح **SQL Editor** ونفّذ محتويات `supabase-setup.sql` بالكامل.
   - ينشئ الجداول `store_data` و `orders` (مع عمود `crypto_network`) و `messages` + سياسات RLS
   - يملأ `store_data` بكتالوج المتجر الافتراضي (12 منتجاً، 8 أقسام، 3 كوبونات، إعدادات crypto) — إعادة التشغيل تحدّث البيانات
3. في **Authentication → Users → Add user** أنشئ مستخدم الإدارة
   - البريد: `admin@majorstore.store` ، كلمة المرور: `yemavava91@@@@@#####`
4. تأكد من ضبط `Project URL` و `anon public key` في `js/cloud.js` (موجودان مسبقاً).

> 🔒 الأمان: نستخدم المفتاح العام `anon` فقط في الكود. عمليات الإدارة تتطلب Supabase Auth. **لا تضع `service_role` أبداً في أي ملف عميل.**

## كيف تعمل المزامنة؟

- المتجر: عند الفتح/العودة للتبويب/كل 30 ثانية يجلب `store_data` من Supabase ويعرض منتجات المدير.
- الطلبات: يُحفظ الطلب محلياً أولاً ثم يُرسل إلى `orders` (مع الشبكة المختارة) — يظهر في اللوحة مباشرة.
- الرسائل: زر ✉ أسفل الصفحة → رسالة في `messages` → إشعار badge في لوحة التحكم.
- الدفع الرقمي: إعدادات crypto (شبكات + عناوين + QR) تُحفظ في `settings.cryptoConfig` وتظهر للزائر عند اختيار العملة.
- البيانات المحلية (بدون إنترنت): كل شيء لا يزال يعمل، وتُدمج بيانات السحابة عند توفر الاتصال.
