# NOVA TECH — Electronic Store

متجر إلكتروني عربي احترافي للأدوات الإلكترونية مع لوحة تحكم محلية.

## التشغيل

افتح `index.html` مباشرة أو شغّل خادماً ثابتاً:

```bash
python3 -m http.server 8080
```

ثم افتح `http://localhost:8080`.

## لوحة التحكم

- الرابط: `/admin.html`
- اسم المستخدم: `admin`
- كلمة المرور: `nova2026`

## المزايا

- إدارة المنتجات: إضافة، تعديل، حذف، سعر، مخزون، شارة، أيقونة، صورة.
- إدارة الأقسام.
- تعديل نصوص الصفحة الرئيسية والإحصائيات.
- تعديل هوية المتجر وبيانات التواصل وشريط الإعلان وطرق الدفع.
- سلة شراء وطلب محلي.
- متابعة الطلبات وتحديث حالتها.
- تصميم متجاوب ومتوافق مع الهاتف.

> هذه النسخة تحفظ البيانات في `localStorage` داخل المتصفح. لذلك تظهر التعديلات على نفس الجهاز والمتصفح فقط، ولا تحتاج إلى GH_TOKEN أو قاعدة بيانات خارجية.
