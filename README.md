# MAJOR STORE — Digital Products Store

واجهة متجر رقمية مع لوحة تحكم وربط Supabase لإدارة المنتجات والطلبات والرسائل.

## ما الذي تم تحسينه في هذه النسخة؟

- تحويل المحتوى إلى **متجر قانوني للمنتجات الرقمية**
- إصلاحات لواجهة الدفع والداشبورد
- دعم إدارة المنتجات والطلبات والرسائل من Supabase
- تحسينات على تجربة تسجيل الدخول والنشر للسحابة

## تنبيهات أمنية مهمة

1. **ألغِ أي GitHub token قديم** إذا كان تمّت مشاركته أو تسريبه.
2. **لا تضع كلمة مرور الإدارة داخل README أو الكود**.
3. استخدم دائمًا **Supabase anon key فقط** في ملفات العميل.
4. أنشئ حساب إدارة خاص بك بكلمة مرور قوية.

## ملفات مهمة

- `index.html` — واجهة المتجر
- `admin.html` — لوحة التحكم
- `js/store.js` — البيانات الافتراضية والترجمة
- `js/cloud.js` — تكامل Supabase
- `js/app.js` — منطق المتجر والدفع
- `js/admin.js` — منطق لوحة التحكم
- `supabase-setup.sql` — إنشاء الجداول وسياسات RLS والبيانات الأولية
- `create-admin-user.sql` — قالب لإنشاء مستخدم الإدارة بعد تعديل البريد وكلمة المرور

## إعداد Supabase

1. أنشئ مشروعًا في Supabase.
2. افتح **SQL Editor** ونفّذ `supabase-setup.sql`.
3. عدّل البريد وكلمة المرور داخل `create-admin-user.sql` ثم نفّذه.
4. ضع `Project URL` و `anon key` الصحيحين في `js/cloud.js`.

## التشغيل محليًا

```bash
python3 -m http.server 8080
```

ثم افتح:

- `http://localhost:8080/index.html`
- `http://localhost:8080/admin.html`

## ملاحظات

- النشر للسحابة أصبح **يدويًا** من لوحة التحكم حتى لا يتم استبدال البيانات تلقائيًا بالخطأ.
- إذا استخدمت أكثر من شبكة كريبتو لنفس العملة، سيظهر اختيار الشبكة للعميل في checkout.
- الكوبونات المعطلة لن تُطبق على الطلب.
