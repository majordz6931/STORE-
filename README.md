# MAJOR STORE — Hacking Tools & Cybersecurity Programs

متجر أدوات اختراق وبرامج إلكترونية بهوية cyber داكنة ولوجو دائري متغيّر الألوان، يحمل شعار "MAJOR STORE" في أعلى الموقع بشكل دائم.

## معلومات الدخول

- **المتجر**: افتح `index.html`
- **لوحة التحكم**: افتح `admin.html`
- تسجيل الدخول يتم عبر **Supabase Auth** — أنشئ مستخدم إدارة في `Authentication → Users` (مثال: `admin@majorstore.store` / `yemavava91@@@@@#####`)
  - في المتجر نكتب الاسم فقط: `admin` (يُحوَّل تلقائياً إلى `admin@majorstore.store`)
  - بدون إنترنت يتم قبول بيانات الدخول المحلية (`admin` / `yemavava91@@@@@#####`) في وضع دون اتصال.

## مزايا الموقع

- ثيم cyber داكن بهوية neon (أخضر ساطع + سماوي + بنفسجي)
- 🖼️ بانر MAJOR STORE ثابت في أعلى الموقع (دائم الظهور)
- 🏪 **قاعدة بيانات مشتركة (Supabase)**: أي منتج ينشره المدير يظهر فوراً للزوار من أي جهاز
- ✉️ **زر تواصل عائم** أسفل الموقع — يرسل الزائر رسالة تصل إلى لوحة التحكم (Messages)
- 💵 أسعار بالدولار الأمريكي فقط ($)
- 🌍 دعم اللغتين العربية والإنجليزية - زر `AR/EN` للتنقل بين اللغات
- 💰 طرق دفع متعددة: Bitcoin, Ethereum, USDT (TRC20/ERC20), Litecoin, Monero, PayPal, Visa/Mastercard, Western Union, Wise, BaridiMob/CCP, الدفع عند الاستلام
- 🎟️ كوبونات خصم قابلة للتعديل
- 🛒 سلة شراء محلية + طلبات تُرسل إلى Supabase (تظهر في اللوحة)
- ⚙️ لوحة تحكم: منتجات / أقسام / طرق دفع / نصوص الواجهة / إعدادات / طلبات / رسائل

## إعداد Supabase (مرة واحدة)

1. أنشئ مشروعاً في [supabase.com](https://supabase.com).
2. افتح **SQL Editor** ونفّذ محتويات `supabase-setup.sql` بالكامل.
   - ينشئ الجداول `store_data` و `orders` و `messages` + سياسات RLS:
     - الزوار: قراءة المتجر + إنشاء طلب + إرسال رسالة
     - المسؤول (مصادق عليه): القراءة/الكتابة/الحذف للكل
   - يملأ `store_data` تلقائياً بكتالوج المتجر الافتراضي (12 منتج، 8 أقسام، 3 كوبونات) فتعمل الصفحة فوراً قبل أي تعديل من لوحة التحكم.
3. في **Authentication → Users → Add user** أنشئ مستخدم الإدارة
   - البريد: `admin@majorstore.store` (أو أي بريد تريده ثم اكتبه كاملاً في صفحة الدخول)
   - كلمة المرور: `yemavava91@@@@@#####`
4. تأكد من ضبط `Project URL` و `anon public key` في `js/cloud.js` (موجودان مسبقاً).

> 🔒 الأمان: نستخدم المفتاح العام `anon` فقط في الكود. عمليات الإدارة المميزة تتطلب Supabase Auth (token ينتقل تلقائياً). **لا تضع `service_role` أبداً في أي ملف عميل.**

## التشغيل

```bash
cd store
python3 -m http.server 8080
```

ثم افتح:
- `http://localhost:8080/index.html` → المتجر
- `http://localhost:8080/admin.html` → لوحة التحكم

## كيف تعمل المزامنة؟

- المتجر: عند الفتح/العودة للتبويب/كل 30 ثانية يجلب `store_data` من Supabase ويعرض منتجات المدير.
- الطلبات: يُحفظ الطلب محلياً أولاً ثم يُرسل إلى `orders` — يظهر في اللوحة مباشرة.
- الرسائل: يفتح الزائر زر ✉ أسفل الصفحة، تُحفظ الرسالة في `messages`، ويصل إشعار (badge) في لوحة التحكم.
- البيانات المحلية (بدون إنترنت): كل شيء لا يزال يعمل، وتُدمج بيانات السحابة عند توفر الاتصال.
