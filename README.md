# MAJOR STORE — Gaming & Consoles

متجر ألعاب وإكسسوارات PlayStation موجه للاعب الجزائري، اسمه **MAJOR STORE** بهوية حمراء ولوجو دائري يتغيّر لونه باستمرار (حلقة ألوان كونيك).

## الوصول

- المتجر: `index.html`
- لوحة التحكم: `admin.html`
- اسم المستخدم: `admin`
- كلمة المرور: `major2026`

## التشغيل

```bash
python3 -m http.server 8080
```

ثم افتح `http://localhost:8080`.

## المزايا

- إدارة المنتجات (إضافة، تعديل، حذف، سعر قدیم، مخزون، شارة، أيقونة، لون).
- إدارة الأقسام.
- تعديل نصوص Hero والإحصائيات.
- إدارة الهوية وبيانات التواصل.
- سلة وطلب ببيانات العميل.
- متابعة الطلب وتغيير حالتها.
- لوجو دائري SVG مع حلقة ألوان كونيك متدرّجة باستمرار.
- تصميم متجاوب مع الهاتف والحاسوب.

> تُحفظ البيانات في `localStorage` داخل المتصفح، لا حاجة إلى GitHub Token ولا سيرفر خارجي.
